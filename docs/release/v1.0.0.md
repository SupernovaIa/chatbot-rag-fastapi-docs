## 2. Cuerpo del release (GitHub Releases)

**Título:** `v1.0.0 — Chatbot RAG sobre FastAPI docs`

```markdown
Primera versión estable. Chatbot RAG sobre la documentación pública de FastAPI,
construido extremo a extremo bajo la restricción **cero tarjeta**: todo corre en
local con Docker y el único proveedor externo es Google AI Studio (free tier).

## Qué incluye

- **Indexación** (bloque B): corpus pinned de FastAPI → Azurite → chunking
  Markdown-aware → embeddings `gemini-embedding-001` (1536 dims) → pgvector
  (HNSW + GIN). Idempotente por `chunk_hash`.
- **Retrieval híbrido** (bloque R): denso (coseno) + BM25 fusionados con RRF en
  una sola query SQL, LLM-reranker RankGPT (Gemini Flash) con fallback robusto y
  reescritura multi-turn con sliding window N=5.
- **Chat** (bloque CH): endpoint `/chat` con SSE, citas `[N]`, historial
  persistente y caching implícito del prefijo del prompt.
- **Auth** (bloque AU): FastAPI Users, email + password + bcrypt, JWT en cookie
  httpOnly, scoping de conversaciones por usuario.
- **Frontend** (bloque D): React + Vite, streaming token a token, chips de citas
  clicables, selector de sesiones, build de producción con nginx.
- **Evaluación** (bloques G + E): dataset gold de 40 ejemplos revisado a mano;
  gate **determinista** por PR (recall@5 / MRR) + suite RAGAS con Gemini Pro como
  juez en una nocturna no bloqueante (ADR-012).
- **Observabilidad** (bloque F): spans por fase en Phoenix (OpenTelemetry /
  OpenInference), modelo de coste por turno y dashboards de salud/calidad/coste.
- **Seguridad** (bloque S): defensa en profundidad en 5 capas (safety filters →
  guardrail Flash → system prompt robusto → filtro de output con redaction PII →
  incidentes + rate limiting), OWASP LLM01/LLM02.

## Verificación de la release

Validada end-to-end desde un clone fresco (`docker compose down -v` + arranque
desde cero):

- Stack: 5/5 servicios `healthy`.
- Indexado: 145 blobs → 1772 chunks en pgvector.
- Conversación multi-turn de 5 turnos con citas y resolución de contexto.
- Eval gate determinista: **PASS** (recall@5 1.000, MRR 0.883).
- Red team: **20/20 bloqueados**, 4/4 inyección indirecta, 3/3 controles.
- Phoenix: 331 spans cubriendo todo el pipeline + incidentes de seguridad por capa.
- CI: regresión deliberada **bloqueada** por el eval gate.
- 279 tests verdes, ruff limpio, gitleaks sin hallazgos.

## Stack

Python 3.12 · FastAPI · LangChain v1 · Postgres 17 + pgvector · Azurite ·
Arize Phoenix · React + Vite · Gemini (Flash / Pro / embedding-001) ·
GitHub Actions.
```
